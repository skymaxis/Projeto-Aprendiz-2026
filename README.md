# Projeto-Aprendiz-2026
GESTÃO DE ALUNOS PROJETO APRENDIZ 2026 — V8.5.4

O que esta versão entrega:
- Dashboard estável sem dependência de bibliotecas externas
- Gráfico comparativo com opções em Português Brasil
- Radar corrigido sem crescimento infinito
- Cards de totais clicáveis + botão explicativo (!)
- Top 5 igrejas em formato de botões
- CRUD completo de alunos, turmas e aulas
- Calendário navegável por mês com programação por data
- Presença por turma com Presente / Ausente / Justificada
- Campo de justificativa com até 2000 caracteres
- Ficha do aluno para impressão em PDF
- Upload de foto e documentos no cadastro do aluno
- Tema claro/escuro/automático
- Upload de logo
- Importação/exportação local em JSON, CSV e logs
- Estrutura separada para configuração de nuvem sem quebrar a abertura do app

Como usar:
1. Abra o arquivo HTML no Chrome, Edge ou outro navegador moderno.
2. O sistema salva os dados no próprio navegador do dispositivo.
3. Use a aba “Dados” para exportar backup JSON e restaurar depois.
4. A parte de nuvem/publicação real está separada em campos de configuração para futura integração.

Observação:
Recursos que exigem backend real, autenticação online, convite por e-mail ou sincronização em nuvem ainda dependem de implementação de servidor/provedor externo. Eles foram mantidos isolados para evitar os erros de abertura e reinicialização relatados nas versões anteriores.
